What to watchParameters, automatic objects, return values, and the point where a lifetime ends.

A value returns. An object doesn’t.

The local object result belongs to this invocation of twice. When the call finishes, its automatic objects no longer exist. The returned value can still initialize answer in the caller.

  • A call creates a new context.
  • A parameter receives an argument value.
  • Automatic objects have bounded lifetimes.

The stack visualization is an explanatory model of this example; C does not require a particular physical stack layout.
